# Калькулятор

##  Описание
Простой и удобный калькулятор для выполнения базовых арифметических операций. Проект создан в рамках учебной работы по командной разработке с использованием Git и CI/CD.

Возможности:
- Сложение, вычитание, умножение и деление.
- Работа с десятичными числами.
- Простой и понятный интерфейс.

## Установка и запуск

### Требования
- Python 3.8 или выше
- pip (менеджер пакетов Python)
<img width="1920" height="1039" alt="image" src="https://github.com/user-attachments/assets/b7d2f7df-d5fd-4be1-9177-497e49a7bdf4" />

### Установка
1. Клонируйте репозиторий:
git clone https://github.com/DebVladosa228/-ci-cd-student-project_2.git
cd -ci-cd-student-project_2

2. (Опционально) Создайте виртуальное окружение:
python -m venv venv
venv\Scripts\activate

3. Установите зависимости (если есть файл requirements.txt):
pip install -r requirements.txt

### Запуск
python main.py

## Использование
После запуска программа предложит ввести первое число, затем оператор (+, -, *, /) и второе число. Результат будет выведен в консоль.

Пример:
Введите первое число: 10
Введите оператор (+, -, *, /): *
Введите второе число: 5
Результат: 50
